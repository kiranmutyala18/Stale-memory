    The benchmark

    24 cases, four behaviours.

    Each case gives the assistant a small dated memory and a user message on 14 November 2026.

    useStable or recent fact. Answer directly.
    verifyOld fact that changes. Check it first.
    updateNewer note replaces older. Use the newer.
    expiredEvent has passed. Don’t treat as current.
    Method

    How it works, and where it’s weak.

    Cases are hand-written and checked by script. Each runs in three formats: plain notes, dated notes, and dated notes with a short guidance paragraph. Independent Claude runs wrote all 72 replies, scored first by rules and then read by hand. Two calls were borderline: the plain-notes relationship reply counts as a check because it asks whether the evening is with the named partner or someone else; the dated one counts as neither because it never names the partner.

    • The 365-day and 90-day horizons are my assumptions, not measurements.
    • 24 cases, one model family, one reply per prompt. No statistics are claimed.
    • The guidance format states the rule, so it measures instruction-following.
    • Too easy in places: update and expired cases score 6/6 even without dates, because the note itself says “Joined Microsoft” or “interview on Nov 6”. The next version needs implicit staleness.
    • Scoring rules were fixed after reading replies (5 of 72 outcomes changed), applied to every format equally.

    Next: harder cases, more models, human ratings, and a confidence-decay hint attached to each note so the assistant checks only when it should.
